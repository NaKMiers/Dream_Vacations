# 🏝️ Dream Vacations – Travel Landing Page

Dream Vacations là một **landing page hiện đại, responsive** được thiết kế dành cho các dịch vụ **du lịch nghỉ dưỡng, resort và tour trọn gói**. Dự án được xây dựng bằng **ReactJS**, tập trung vào trải nghiệm người dùng, tốc độ tải trang và giao diện hấp dẫn.

## 🚀 Demo

👉 [Xem bản demo trực tiếp tại đây](https://dream-vacations-01.netlify.app)

---

## 🔍 Tính năng chính

- 🎯 Giao diện bắt mắt, thu hút người dùng từ cái nhìn đầu tiên
- 📱 Responsive 100% trên mọi thiết bị (mobile, tablet, desktop)
- 🧭 Navigation bar cố định, cuộn mượt mà
- 🗺️ Thẻ giới thiệu điểm đến (destinations cards)
- 🎫 Call-to-action rõ ràng: Đặt tour, Nhận ưu đãi
- 🌄 Hình ảnh chất lượng cao, tối ưu hiển thị
- 🌐 Tương thích với SEO cơ bản (cấu trúc heading chuẩn)
- 🧩 Component-based structure giúp dễ mở rộng và tái sử dụng

## ⚙️ Cài đặt và chạy dự án cục bộ

```bash
# 1. Clone repository
git clone https://github.com/NaKMiers/Dream_Vacations.git

# 2. Cài đặt các package
cd Dream_Vacations
npm install

# 3. Chạy project
npm start
```

Truy cập trình duyệt tại: `http://localhost:3000`
